- Logic-level plagiarism detection by parsing submissions into Abstract Syntax Trees and comparing structure.
- Semantic similarity scoring with Sentence Transformer embeddings.
- Queries the GitHub Code Search API for potential matches found online.
- Generates a similarity score and feedback report for educators, coding platforms and recruiters.
